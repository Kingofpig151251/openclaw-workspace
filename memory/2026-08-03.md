#### 後端審計報告

##### 🔴 High（6個）
1. **`sid` 遺漏** — write-tools.ts 的 removeStudio 用了舊字段名 `sid`，查詢永遠返回 0，課程變孤兒數據
2. **CORS production 被禁** — NODE_ENV=production 時不註冊 CORS，前後端分離部署 API 全 403
3. **Admin 無輸入驗證** — 所有 PUT/POST 用裸 `req.body as {...}` 斷言，其他路由都有 Zod
4. **ESM 裡用 `require()`** — admin.ts 用 `require('node:crypto')`，ESM 項目會崩
5. **Auth 無限流** — /auth/login 和 /auth/register 完全裸奔，暴力破解風險
6. **內存限流器不適合生產** — Map 存限流狀態，重啟丟失、無法水平擴展

##### 🟡 Medium（6個）
7. 殭屍工具名 — ai.ts 還有 getRecurringSeries / editCourseSeries 的 display name
8. notFound() 重複定義 — shared.ts 和 admin.ts 簽名不同
9. 錯誤響應格式不統一 — 有的 `{ error: { code, message } }`，有的 `{ error: 'string' }`
10. req.user 到處 `as any` — 已聲明 FastifyJWT 類型但沒用
11. 全局 60+ 處 `as any` 類型斷言
12. formula-eval.ts 30+ 處 `any`

##### 🟢 Low（3個）
13. console.log/error 散佈各處
14. ai.ts 有未使用的 import
15. formula-eval.ts evaluateCondition 可提取為獨立函數

#### 修復完成（7個，含手動修的 #1）

| # | 問題 | 修復 |
|---|------|------|
| 1 | sid 遺漏 | 手動修：sid → studioId |
