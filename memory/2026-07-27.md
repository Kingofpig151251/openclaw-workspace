## Compaction 配置修復

- 問題：auto-compaction 經常不觸發
- 原因：
  1. `reserveTokensFloor: 65536` 太高，觸發閾值 = 200K - 65K = 135K（67%才觸發）
  2. Model `contextWindow` 未聲明，OpenClaw 以為是 200K，但訊飛星火實際有效窗口更小
  3. 訊飛星火 token 計數不可靠（API 回報過 input: 1.5M 這種離譜數字）
- 修復：
  - `reserveTokensFloor`: 65536 → 20000
  - Model `contextWindow`: 未設定 → 128000
  - 新觸發閾值：128K - 20K = 108K tokens（84%）
- Gateway 已重啟生效，`openclaw status` 顯示 "128k ctx"

## Compaction 配置修復

- 問題：auto-compaction 經常不觸發
- 原因：
  1. `reserveTokensFloor: 65536` 太高，觸發閾值 = 200K - 65K = 135K（67%才觸發）
  2. Model `contextWindow` 未聲明，OpenClaw 以為是 200K，但訊飛星火實際有效窗口更小
  3. 訊飛星火 token 計數不可靠（API 回報過 input: 1.5M 這種離譜數字）
- 修復：
  - `reserveTokensFloor`: 65536 → 20000
  - Model `contextWindow`: 未設定 → 128000
  - 新觸發閾值：128K - 20K = 108K tokens（84%）
- Gateway 已重啟生效，`openclaw status` 顯示 "128k ctx"
